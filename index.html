01
Sistema IoT · Trabalho de Conclusão de Curso

PMCA — Plataforma de Monitoramento do Consumo de Água

Dashboard web próprio do PMCA — consumo acumulado, vazão atual, histórico e conexão segura do ESP32
Problema

Desperdício de água é recorrente em residências e pequenos negócios, muitas vezes por falta de visibilidade do consumo em tempo real.

Solução

O ESP32 interpreta os pulsos do sensor YF-S201, calcula vazão e volume e envia as leituras por HTTPS para uma API própria. O backend utiliza FastAPI, Uvicorn, SQLAlchemy e PostgreSQL; autenticação de usuários, API key exclusiva por dispositivo e dashboard responsivo completam o fluxo.

Resultado

Protótipo funcional de ponta a ponta, publicado na Railway e acessível pela Internet. O dispositivo pode ser levado para outra rede: um portal de configuração recebe Wi‑Fi e API key, armazena os dados em LittleFS e mantém uma fila local quando a conexão falha.

BackendFastAPI, Uvicorn, SQLAlchemy
DadosPostgreSQL gerenciado na Railway
SegurançaHTTPS, JWT, bcrypt e API key

Advanced Registration System

Tela de cadastro do sistema — formulário com validação de nome e idade
Problema

Entender na prática como um sistema web completo é estruturado: da configuração do ambiente até a rota que responde ao usuário.

Solução

Sistema de cadastro construído com Django (framework web em Python), organizando o projeto em apps, definindo rotas (URLs), views e templates HTML estilizados com Bootstrap 5. Prática de configuração de ambiente virtual Python, models e formulários com validação de campos (nome e idade).

Resultado

O projeto virou um repositório público e consolidou a base que usei depois no backend do PMCA: organização de rotas, validação de dados e separação de responsabilidades.
